# Site-DST-s
Portal informativo sobre Doenças Sexualmente Transmissíveis (DSTs), desenvolvido para facilitar o acesso a informações claras e confiáveis sobre prevenção, transmissão, sintomas, diagnóstico e tratamento. O projeto também busca combater a desinformação e o preconceito, promovendo educação em saúde e acesso aos serviços de atendimento.
